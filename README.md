# Web eDITA

A browser-based DITA (Darwin Information Typing Architecture) editor with live preview functionality.

## Features

- **Live Preview**: See your DITA content rendered in real-time as you edit
- **Drag & Drop**: Simply drop your .dita or .xml files onto the interface
- **Paste Support**: Paste DITA content directly from your clipboard
- **Sample Content**: Try out the editor with built-in sample DITA content
- **Dual Pane View**: Side-by-side editor and preview panes with resizable divider
- **Code/Edit Toggle**: Switch between viewing source code and editing mode
- **Save Functionality**: Download your edited DITA files
- **Collapsible Panes**: Maximize your workspace by collapsing either pane

## Supported DITA Elements

- Concept, Task, and Reference topics
- Sections, titles, and short descriptions
- Lists (ul, ol, dl)
- Notes with different types (tip, warning, caution, important)
- Code blocks and inline code
- Tables
- Cross-references and images
- And more standard DITA elements

## Usage

1. Open `index.html` in a modern web browser
2. Choose one of these options to get started:
   - Drag and drop a .dita file onto the drop zone
   - Click "Choose File" to browse for a .dita file
   - Click "Paste Content" to paste DITA XML from your clipboard
   - Click "Try Sample" to load example DITA content

## Requirements

- Modern web browser with JavaScript enabled
- No server or build process required - runs entirely in the browser
